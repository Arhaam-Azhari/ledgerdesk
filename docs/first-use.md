# Starting a workspace

LedgerDesk keeps one business in USD per installation. The Overview shows a short starting guide while the ledger has no posted entries. Owners can open the opening-books screen from it; bookkeepers are reminded to ask an owner for carried balances. Reviewers keep their read-only reports view.

For a business with prior records, review the cutover, supported balances and unpaid documents in [opening books](opening-books.md) before posting new activity. Use the broader import when carrying unpaid invoices or bills; do not record the same bank funds through both opening methods. Unsupported histories need review before using this installation.

A business starting with no prior balances can add customers or vendors and record its first transaction. Post invoices when earned and record payments separately. Check dated reports, then review bank imports and reconciliation. The sample customer is fictional; add your own customer before using real records.

The guide disappears after the first accounting entry. It is navigation help, not a record that setup has been completed or checked. It does not create balances or skip any posting checks.

Before using real records, follow the [protected backup procedure](encrypted-backups.md) and check a recovered copy. Backups and retention still need an operator.
